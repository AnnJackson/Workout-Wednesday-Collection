- **Published:** April 13, 2021

- **Author:** Ann Jackson

## Introduction

Lately Ann has been working with Google Analytics data, so she thought she'd pass on a data set to the community! This data set was created by the audience itself – it's extracted directly from the Workout Wednesday website analytics.

This week's challenge focuses on a lot of little things coming together – dashboard design, formatting, and reference lines. The big "aha" moment in this challenge is working with duration/time in the format of minutes and seconds, most specifically getting the reference lines to display.

## Requirements

- Dashboard Size: 1300px by 1000px
- # of Sheets – up to you
- Create 4 Metrics with Trend lines:
  - Total Sessions — trend weekly, with a weekly average reference line
  - Average Session Duration (Session Duration/Sessions) — trend weekly, with an overall (aggregate) reference line, formatted in minutes and seconds
  - Bounce Rate (Bounces/Sessions) — trend weekly, with an overall (total) reference line
  - Average Time on Page (Time on Page/(Pageviews − Exits)) — trend weekly, with an overall (aggregate) reference line, formatted in minutes and seconds
- Colors: Purple #7830b6, Green #72b966, Yellow #f7cc63, Darker Blue #628cb9, Lighter Blue #58b8ba

FYI: Since this is a static data set, it's filtered to 12/29/2019 to 4/10/2021.

## Dataset

This week uses an export from Google Analytics (the Workout Wednesday website's own analytics).
